# Simulador-de-Lancamento-Obliquo
Site projetado para auxiliar o estudo sobre a matéria de Lançamento Oblíquo, na área de Física Mecânica.
O projeto foi desenvolvido com o auxílio do Claude e revisado por 3 estudantes de Informática do Insituto Federal do Espírito Santo.
Nele, encontra-se um programa interativo que calcula a trajetória do lançamento de um ponto ideal e um foguete de garrafa pet.
O usuário deve informar as variáveis como velocidade inicial, ângulo de lançamento e massa do projétil. 
Após isso, é gerada a trajetória do disparo, bem como a apresentação dos resultados de fórmulas comuns no Ensino Médio.
Também há uma apostila virtual contendo uma explicação sobre fórmulas, funcionamento e aplicação física.
